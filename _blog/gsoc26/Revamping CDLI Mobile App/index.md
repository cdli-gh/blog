## Project Overview

Hi, I'm [Shiva Gupta](https://www.linkedin.com/in/shivagupta14/), participating in Google Summer of Code 2026 with CDLI.

I've been accepted for the project **Revamping CDLI Mobile App (React Native)**. Despite the name, this is effectively a from-scratch build, none of the earlier CDLI mobile apps are alive, maintained, or working on current devices, so there is no live app to revamp. The goal is to give researchers, students, and enthusiasts a modern, on-the-go way to explore the Cuneiform Digital Library Initiative's catalogue of cuneiform tablets. I'll be building the app on a current React Native foundation with a clean architecture, a fresh design system, and direct integration with the current CDLI API including the features the community has been asking for, like improved search, artifact bookmarking, offline browsing, and more.
